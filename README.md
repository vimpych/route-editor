# route-editor

Форма карточки места для внутреннего бота @moderation_route_Bot.
Только статическая страница: ключей и данных здесь нет, всё чтение и
запись идут через функцию бота, которая проверяет подпись Telegram и
белый список редакторов. Исходники живут в основном репозитории
(`app/editor-form`), сюда выкладывается готовая копия.
